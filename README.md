# Verity website

Live at **https://ambicuity.github.io/verity/** — served by GitHub Pages from the root of `main`.

| File | What it is |
|---|---|
| `index.html` | The interactive Mac + iPhone prototype (self-contained bundle, patched by `tools/patch_prototype.py`) |
| `product.html`, `trust.html`, `pricing.html`, `company.html`, `pilot.html`, `compare.html` | Marketing pages, generated by `tools/build_pages.py` |
| `404.html` | Branded not-found page |
| `prototype.html` | Redirects old links to the homepage |
| `assets/site.css` | Shared styles (tokens match the prototype) |

## Updating

```bash
# After re-exporting the prototype:
python3 tools/patch_prototype.py "path/to/Verity Prototype.html"

# After editing page copy in tools/*.py:
python3 tools/build_pages.py

git add -A && git commit -m "docs: update site" && git push
```

Pages redeploys in about a minute. GitHub's CDN may cache old HTML for up to 10 minutes.

The pilot form has no backend (GitHub Pages is static); it validates input and opens a pre-filled email.
